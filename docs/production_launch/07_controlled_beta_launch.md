# Controlled Beta Launch Plan

## Objective

Kichik allowlist cohort bilan xavfsiz soft launch o'tkazish.

## Tasks

- `BETA_ALLOWLIST_USER_IDS` ni faqat tanlangan cohort bilan to'ldirish.
- Feature flag'larni bittalab yoqish.
- 10-20 user pilot bilan boshlash.
- So'ng 50-100 user beta ga o'tish.
- Activation, retention, referral, engagement signal'larini o'lchash.
- Support and incident channel tayyorlash.

## Exit criteria

- Beta cohort access explicit.
- Every risky feature rollbackable.
- Metrics from beta usable for launch decision.
